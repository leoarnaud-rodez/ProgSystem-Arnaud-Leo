Q1) Que garanti un système RTOS
		Le système RTOS est à temps réel donc il garanti un temps maximum d'execution pour un processus. Dans le cas ou ce processus dépasse ce temps maximum il est tué instantanément.
		Il s'agit des système utilisé majoritairement pour les fusées ou les grandes chaînes d'industrie.


Q2) Que garanti un système moderne (noyau/OS) -> sécurité / perf / user / processus
		Un système moderne suivant l'architecture noyau / OS garanti le lancement des programmes, les basculement entre les procecssus, la getion mémoire et le cloisement entre Users.
		Cet architecture moderne garanti également l'isolement entre les processus et la sécurité via une athentification ou autre.


Q3) Une variable dans un language de prop.

a) Distinguez ce qui appartient au language et au matériel
RAPPEL : a += 5 -> LAOD / ADD / STORE
		le langage fourni le type et la taille (et le nom). La machine quant à elle fourni la valeur, l'adresse et la représentation (l'endianness : le gig endiant et le litle endient)

b) Qu'est ce que l'on peut faire en Assembleur et non en java ?
		En assembleur, on manipule directemement les registres et les allocations mémoire des variables ("mémoire") alors qu'en java nous n'avons pas le controle sur la gestion mémoire de la JVM.
		De plus, en assembleur c'est à nous de garantir la taille

Q5) Considérons une image de taille 50x100 en RGBA.

a) Donnez l'équation qui permet d'encoder (x,y,c) -> (i) donc 3D -> 1D
	((y * longueur) + x) * 3 + z            // 3 est ici la profondeur -> RGB
	((y * 50) + x) * 4 + c					// 4 car RGBA
	
b) Déduisez l'équation inverse.
	c = i%4 // composant a composant       q = i/4      (y * 50) + x  // pixels a pixels
	x = q%50 							   y = q/50   // x et y tout 2 utiles pour la lecture

c) Déterminez l'équation d'interpolation permettant de transformer [a,b] -> [c,d] (indice, passage par [0,1])
	z = f(x) = (x-a) / (b-a)
	w = f(x) = z(d-c)+c
